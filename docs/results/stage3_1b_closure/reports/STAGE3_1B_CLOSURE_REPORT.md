# Stage 3.1B Closure Report

## Scope

This report was generated by `stage3.analysis.run_stage3_1_closure_package`.

The closure package uses existing Stage 3.1B runners and analyzers. It does not
introduce a new environment, agent, or experimental protocol.

The package is split into five publication-facing layers:

1. `matrix`: 3x3 reward x threat conflict surface.
2. `balanced ablation`: balanced-conflict ablation summary.
3. `one-shot shock`: negative event-aligned carryover.
4. `one-shot treat`: positive event-aligned carryover.
5. `diagnostics`: placebo-window, carrier, and ablation-localization checks.

## Matrix layer

The matrix layer is generated from `stage3.analysis.run_stage3_1b --grid 3x3`.
It describes the reward x threat conflict surface and produces heatmaps for
choice probability, timeout probability, commit latency, deliberation proxy,
junction pause, reorientation, and mode-at-junction diagnostics.

## Balanced ablation layer

The balanced ablation layer summarizes the R1_T2 conflict condition across the
configured ablations. It is used to locate which removed mechanisms disrupt
balanced-conflict behavior.

## One-shot shock layer

The shock protocol introduces a single negative high-amplitude event and tracks
post-event deformation of target-path probability and carrier variables.

## One-shot treat layer

The treat protocol introduces a single positive high-amplitude event and tracks
post-event deformation of target-path probability and carrier variables.

## Diagnostics

Diagnostic outputs include placebo-window nulls, seed-level SEM plots,
carrier-effect tables, and ablation-localization summaries.
